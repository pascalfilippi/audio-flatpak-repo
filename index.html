Personal test Flatpak repo.

Add the remote

flatpak remote-add --user --if-not-exists \
  audio-flatpak https://pascalfilippi.github.io/audio-flatpak-repo/audio-flatpak.flatpakrepo

Built and published by GitHub Actions from each source repo. The published repo/ directory is an ostree archive-z2 repo served as static files.
