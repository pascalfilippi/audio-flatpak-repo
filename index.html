Pascal's Audio Flatpaks

Personal test Flatpak repo for a low-latency Reaper + yabridge stack on Linux/PipeWire.

Add the remote

flatpak remote-add --user --if-not-exists \
  audio-flatpak https://pascalfilippi.github.io/audio-flatpak-repo/audio-flatpak.flatpakrepo

Install

flatpak install --user audio-flatpak fm.reaper.Reaper
flatpak install --user audio-flatpak io.github.audioflatpak.YabridgeManager
flatpak install --user audio-flatpak org.freedesktop.LinuxAudio.Plugins.yabridge//25.08
